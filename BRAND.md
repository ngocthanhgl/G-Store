# Forkly — brand guide

## Name
**Forkly** — an Android app store for apps published on GitHub Releases.
Written `forkly` (lowercase) in the logo, `Forkly` in prose.
Forkly is an independent project and is not affiliated with, endorsed by or sponsored by GitHub, Inc.
Use "GitHub" only descriptively (e.g. "apps from GitHub releases"), never as part of the product name.

## Idea
The mark is the letter **F** drawn as a git branch: a trunk that forks into two branches, each ending in a commit node.
"Forkly" = fork + the friendly `-ly`: apps straight from the source.

Wordmark is Poppins Bold converted to outlines — no font install needed.

|------|-----|

| Mark gradient (on light) | `#FF7A59` → `#7B4DFF` |
| Wordmark (light) | `#231B4D` |
| Wordmark / mark (dark, on gradient) | `#FFFFFF` |
| Shadow | `#1A1050` at 22% |

## Don'ts
- Don't recolour the nodes or change the branch angles.
- Don't put the gradient mark on a busy photo; use the white version on the brand gradient instead.
- Don't use the GitHub logo or Octocat next to the mark.
